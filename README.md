# Confidential Medical Data Analysis



### Setup 

```bash
uv sync
```

### Data

Patient data generated with: https://github.com/synthetichealth/synthea

instruction:
1. clone repo to synthea/
2. cd synthea/
3. Run run_synthea.bat (windows) or run_synthea file (linux) with -p <number> of samples
4. Data is stored in synthea/output/fhir
